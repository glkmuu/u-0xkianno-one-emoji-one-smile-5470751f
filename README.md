A single waving hand — the warmest hello a stranger can give, written as exactly one emoji.

## What it does

`main.py` writes exactly one emoji to `entry.txt`: a waving hand
(U+1F44B, "Waving Hand"). One Unicode code point, four UTF-8 bytes,
no words, no caption, no explanation. A wave is the greeting a
stranger actually gives — friendly at first glance, readable by
anyone of any age or background, with no irony, intimacy, or
in-joke. It is a chosen gesture rather than the first smiley face
that comes to mind, and it needs no context to land: a hand raised
in hello is warmth in one glance.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the single emoji to `out/entry.txt`. The program uses
only the Python standard library, needs no network, and is fully
deterministic — every run writes the same bytes.
